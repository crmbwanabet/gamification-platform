## Task 1: Engine + tests (TDD)
**Files:** `tests/coinflip-engine.test.mjs`, `lib/coinflip/engine.mjs`
1. Write the test first (style of `tests/njuka-engine.test.mjs`: `node:test`, `assert/strict`, import from `../lib/coinflip/engine.mjs`). Cases from the spec:
   - `payoutFor` gives 19/38/57/95 for 10/20/30/50.
   - Injected rng returning a low value yields `EAGLE`, a high value yields `100x` (one test per face).
   - `win === (face === pick)`; `payout` is `payoutFor(stake)` on a win and 0 on a loss.
   - Invalid stake (0, 15, '10', NaN) and invalid pick ('heads', undefined) throw.
   - 10 000 default-rng flips: each face lands within 47-53%.
2. Run `node --test tests/coinflip-engine.test.mjs`. Expect FAIL (module not found).
3. Implement this exact contract:
```js
export const STAKES = [10, 20, 30, 50];
export const FACES = ['EAGLE', '100x'];
export function payoutFor(stake)  // Math.round(stake * 19 / 10), integer maths; throws on invalid stake
export function resolveFlip(stake, pick, rng = defaultRng) // -> { face, win, payout }
// rng(): number in [0,1). face = rng() < 0.5 ? 'EAGLE' : '100x'
// defaultRng: crypto.getRandomValues(new Uint32Array(1))[0] / 2**32  (globalThis.crypto; Node 18+ and browsers)
```
4. Verify: the targeted test passes, then `npm test` is green.
5. Commit: `feat(coinflip): pure engine + tests`

## Task 5: CoinFlipGame state machine
**Files:** `components/games/coinflip/CoinFlipGame.jsx`
Props: `{ onClose, closing, balance, onSpend, onRound }`. Imports: `resolveFlip, STAKES, FACES, payoutFor` from `@/lib/coinflip/engine.mjs`, `TutorialModal` (`tutorialKey="coinflip"`), candy kit, `Coin`.
1. State: `phase` (`idle|flying|result`), `stake`, `pick`, `outcome`. Last stake/pick remembered: init from `localStorage` key `coinflip:last` (try/catch, JSON `{stake,pick}`), else stake 10 / pick null; save on change. A remembered stake above the balance falls back to the highest affordable tier.
2. Layout inside `CandyScreen`, fits 360x640 with no scroll: coin area (top), result line under it, stake chip row (10 violet, 20 blue, 30 red, 50 green; chips above balance disabled; selected = gold ring, siblings dim), pick row (EAGLE green, 100x violet; same selection styling), large green FLIP with gold "WIN 1.9x" caption. "Not enough coins" line when balance < 10. All targets >= 56px.
3. FLIP handler. Guard with a ref lock (`flyingRef`) plus `!pick` / `stake > balance` so rapid taps cannot double-charge. Then `outcome = resolveFlip(stake, pick)`; call `onSpend(stake)` immediately; set `pendingRef.current = { stake, win, payout }`; `phase = 'flying'`. FLIP is `disabled` while flying.
4. `Coin.onLanded`: `phase = 'result'`, then `fireRound()`. Win: "YOU WIN" + big `+{payout}` with gold glow. Loss: the other face shows, "So close!". Stake and pick stay selected; FLIP again is one tap.
5. `fireRound()` contract: take `pendingRef.current`, null it first, then if it existed call
```js
onRound({ stake, win, payout })   // payout = full return on a win (stake*1.9), 0 on a loss
```
   Nulling before the call guarantees exactly-once.
6. Unmount cleanup: `useEffect(() => () => fireRound(), [])` (refs only, so no stale closure). Closing mid-flight delivers the pending round immediately and never twice.
7. `?` opens `TutorialModal`; red X calls `onClose`.
8. Verify: `npm run build`. (Behaviour is checked live in Task 7.)
9. Commit: `feat(coinflip): game screen and state machine`
