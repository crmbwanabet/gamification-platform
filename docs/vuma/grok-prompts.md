# Vuma Katongo: Grok art prompts, one per story stage

Reference: `gamification avatar (Vuma Katongo).jpg` (stage 1 outfit). Attach it to EVERY
Grok prompt as the reference image, so the character stays the same boy.

For each stage, paste the BASE block, then the stage line. Ask for a **1024×1280 portrait**.
Avoid real club crests, sponsor logos and league logos (trademark): kits are identified by colour only.

## BASE block (paste first, every time)

> Pixel-art game character in the exact style of the attached reference image: the same
> faceless African boy/young man (no facial features, dark brown skin, short spiky black hair),
> same chunky 16-bit pixel style, same front-facing standing pose, full body, centred, feet
> near the bottom third. Behind him, a pixel-art background scene of the place described below,
> in a muted warm palette that keeps him clearly readable. No text, no logos, no crests,
> no watermarks. Portrait 4:5.
